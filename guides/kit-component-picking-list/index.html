Before assembly, check four things

  1. Keep variants separate.
    A blue kit and a red kit may use different parts. Multiply each recipe separately before combining shared components.
  2. Check units.
    Pieces, pairs and metres are different units. Confirm the recipe and order use the same unit.
  3. Keep cancelled and duplicate orders out.
    Use the current confirmed quantities. After an order changes, review the picking totals before starting the next batch.
  4. Separate picking from packing.
    A component total tells you what to collect. A per-order checklist tells you which parts belong in each parcel.
