Keep the evidence together

  1. Keep source references.
    Record which report and row supplied the expected quantity, received quantity and payment. Keep the original exports unchanged.
  2. Match the scope before subtracting.
    Check shipment, FNSKU, condition, period and the actual adjustment reference where those fields are available. A shared product code alone is not enough.
  3. Separate facts from decisions.
    An arithmetic difference, your review decision and an accepted reimbursement are different states. Record what is missing instead of assuming it is settled.
  4. Check the actual rules for the actual case.
    Consult the current Seller Central information and your records for eligibility and deadlines. This worksheet does not determine them.
